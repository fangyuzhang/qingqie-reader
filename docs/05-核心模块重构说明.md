## 3. 仓库层：OfflineNovelRepository 混合四职责 → 三类 Repository 边界

### 重构前（lib/offline_repository.dart，622 行）

一个 Repository 同时管：远程站点（JNI）、章节缓存（文件 + epoch）、

```

ReaderRepository      章节/进度/书签/笔记/设置   → BookFileStore + 3 DAO + BookSourceEngine + PreferencesStore
```

ViewModel 与 Widget 拿不到 Dio 与 File 句柄——分层约束由目录结构天然保证。

### 重构后（lib/data/remote/charset_decoder.dart）

```dart
/// BOM → UTF-8 严格试探 → GB18030（Android 原生 Charset）→ 友好报错
static Future<Result<String>> decodeText(Uint8List bytes) async {
  if (_hasPrefix(bytes, _utf8Bom)) return Result.ok(_stripBom(utf8.decode(bytes.sublist(3))));
  try { return Result.ok(_stripBom(utf8.decode(bytes))); } catch (_) { /* 继续 */ }
  final text = await CharsetConverter.decode('GB18030', bytes);   // charset_converter
  if (text != null && text.isNotEmpty) return Result.ok(_stripBom(text));
  return const Result.err(AppError(AppErrorKind.parse, '无法识别文本编码（支持 UTF-8 / UTF-16 / GB18030）'));
}
```

章节拆分正则与上限策略**原样移植**（`TxtParser` 顶部注明来源），并新增作者行识别。

## 7. 新增：划线 / 批注 / 书摘（蜗牛读书式交互）

选句定位用 TextPainter 反查字符偏移（不依赖系统选区，跨模式可控）：

```dart
// lib/feature/reader/widgets/text_block.dart
final offset = _painter.getPositionForOffset(details.localPosition).offset;

// lib/feature/reader/reader_view_model.dart —— 长按自动选中当前句（含句号）
static (int, int) sentenceRange(String text, int offset) {
  const breaks = '。！？；…';
  var s = offset;  while (s > 0 && !breaks.contains(text[s - 1])) s--;
  var e = offset;  while (e < text.length && !breaks.contains(text[e])) e++;
  if (e < text.length) e++;                 // 包含句尾标点
  return (s, e);
}
```

保存后：划线 = 2px 纯色下划线（`text-decoration` 等价实现）；
批注 = 红下划线 + 段落下方的米色「批」字块（可折叠/删除）；
笔记全部落 `notes` 表，切章/切书不丢失。
