# 06 · 开发调试与打包

## 1. 环境要求

| 项 | 要求 |
|---|---|
| Flutter SDK | stable 通道（Dart ≥ 3.10，本项目 `sdk: '>=3.10.0 <4.0.0'`） |
| Android SDK | Platform 34（compileSdk）；minSdk 26（Android 8.0） |
| JDK | 17 |
| 手机 | Android 8.0+，开启开发者选项 + USB 调试 |

## 2. 真机调试（日常开发）

```bash
# 1. 手机插电脑，弹窗「允许 USB 调试」点允许
# 2. 确认设备被识别
flutter devices
#    应看到你的手机（如 Xiaomi • android-arm64 • android 13）

# 3. 首次运行：自动编译并安装
flutter run
```

### 热重载工作流

| 操作 | 终端输入 | 效果 |
|---|---|---|
| 改 Dart 代码 | `r` | 热重载，约 2 秒刷新，**保留页面状态** |
| 改类结构/全局变量 | `R` | 热重启 App（状态重置） |
| 改 `android/` 原生代码 | 重新 `flutter run` | 重新编译安装 |
| 结束运行 | `q` | 退出调试 |

> 提示：阅读器进度、书架数据都在本机，热重启不丢数据（sqflite 持久化）。

## 3. 常用命令

```bash
flutter pub get                 # 首次/改 pubspec 后
flutter analyze                 # 静态检查（目标零 warning）
flutter test                    # 单元测试（预留）
flutter clean                   # 构建异常时清理
flutter build apk              # 打 Release 包（三架构合一）
flutter build apk --split-per-abi   # 按架构分包（体积更小）
```

产物位置：`build/app/outputs/flutter-apk/app-release.apk`

## 4. 项目特有的几个点

1. **平台目录**：仓库只保留 `android/app/src/main/AndroidManifest.xml`（含 INTERNET 等权限）。
   首次拿到的代码如果缺 `android/` 其余文件，在项目根执行 `flutter create . --platforms=android`
   生成平台骨架（不会覆盖已存在的文件与 `lib/`）。
2. **内置书源**：`book_sources/` 目录同时是 pubspec 的 assets 源，应用启动时不会自动导入
   （避免强制写入用户书源列表），需要用户在书源页手动粘贴/导入。两条示例为模板占位域名。
3. **数据位置**：
   - 数据库：`/data/data/<包名>/databases/qingqie.db`
   - 章节缓存：`/data/data/<包名>/app_flutter/books/<书id>/chapters.json`
   - 备份导出：同上 `app_flutter/` 目录下 `qingqie-backup-<时间戳>.json`
4. **GBK 小说**：TXT 导入自动检测 UTF-8 / GB18030（依赖 Android 原生 Charset，
   `charset_converter` 插件）；UTF-16 暂不支持。
5. **网络书阅读**：正文按章抓取并回填 `chapters.json`，第二次打开同一章走本地缓存。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| `flutter devices` 看不到手机 | 换数据线/口；手机上撤销 USB 调试授权后重新允许；安装厂商驱动 |
| `flutter run` 卡在 Gradle | 检查 JDK 17；`flutter clean` 后重试；国内网络可配镜像 |
| `pub get` 版本冲突 | 本项目约束为 `>=3.10.0 <4.0.0`，低版本 Flutter 请先升级 |
| 导入 EPUB 失败 | 确认是标准 EPUB（zip 结构 + container.xml）；加密 EPUB 不支持 |
| 书源校验不通过 | 站点改版 → 用书源页「校验」定位；规则语法见 docs/04 |
| 热重载后界面不动 | 改了类结构/静态字段 → 用 `R` 热重启 |
| 备份恢复后本地书打不开 | 预期行为：备份不含原文件，重新导入一次即可关联（按内容摘要匹配） |

## 6. 发布流程

```bash
# 1. 更新版本号（pubspec.yaml 的 version: x.y.z+build）
# 2. 提交并打 tag
git tag v0.1.0
git push origin v0.1.0
# 3. GitHub Actions 自动：flutter pub get → analyze → build apk --split-per-abi
#    → 上传三个架构 APK 到 Releases（见 .github/workflows/release.yml）
```

Release 页面勾选 `Set as the latest release` 即可供用户下载。
