# 03 · 数据库表结构设计

> 引擎：sqflite（Android 原生 SQLite）。设计目标：替换原项目「SharedPreferences 当数据库」的方案。
> 代码对应：`lib/data/local/app_database.dart`（建表）+ `lib/data/local/dao/*.dart`（数据访问）。

---

## 1. 总览（v1，六张表）

```
categories(1) ──< books(n) ──┬── reading_progress(0..1)
                             ├── bookmarks(n)
                             └── notes(n)
book_sources(n)   （独立，可被 books 引用）
```

| 表 | 职责 | 与原项目 SharedPreferences 键的映射 |
|---|---|---|
| `categories` | 书架分类 | `book_categories.dart` 内 organization 数据 |
| `books` | 书架书籍（本地+网络） | `shelf` + `novel_meta_*` |
| `reading_progress` | 阅读进度（一书一行） | `reading_position_*` |
| `bookmarks` | 书签 | `reader_bookmarks_*` |
| `book_sources` | 书源规则（YAML 原文） | 无（新增） |
| `notes` | 划线/批注/书摘 | 无（新增，HTML 原型已验证） |

## 2. DDL（与 Dart 代码逐字一致）

```sql
-- 分类表：书架分组（在读/想读/读完…用户可增删）
CREATE TABLE categories (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  name       TEXT    NOT NULL,
  sort       INTEGER NOT NULL DEFAULT 0,
  created_at INTEGER NOT NULL
);

-- 书架表：一本书一行；本地书与网络书共用
CREATE TABLE books (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  title         TEXT    NOT NULL,
  author        TEXT    NOT NULL DEFAULT '',
  intro         TEXT    NOT NULL DEFAULT '',
  cover_path    TEXT,                       -- 本地封面文件（EPUB 解出）
  origin        TEXT    NOT NULL,           -- local | network
  format        TEXT    NOT NULL,           -- txt | epub | web
  local_path    TEXT,                       -- 原 TXT/EPUB 路径（仅本地书）
  source_id     INTEGER,                    -- 书源 id（仅网络书）
  book_url      TEXT,                       -- 详情页 URL（仅网络书）
  category_id   INTEGER NOT NULL DEFAULT 1,
  chapter_count INTEGER NOT NULL DEFAULT 0,
  toc_json      TEXT,                       -- 网络书章节列表缓存
  added_at      INTEGER NOT NULL,
  last_read_at  INTEGER NOT NULL DEFAULT 0,
  FOREIGN KEY (category_id) REFERENCES categories(id) ON DELETE SET DEFAULT
);
CREATE INDEX idx_books_category ON books(category_id);
CREATE INDEX idx_books_origin   ON books(origin);

-- 阅读进度表：一书一行，offset 语义随阅读模式（滚动=px，分页=页码）
CREATE TABLE reading_progress (
  book_id        INTEGER PRIMARY KEY,
  chapter_index  INTEGER NOT NULL DEFAULT 0,
  chapter_title  TEXT    NOT NULL DEFAULT '',
  offset_value   REAL    NOT NULL DEFAULT 0,
  percent        REAL    NOT NULL DEFAULT 0,
  updated_at     INTEGER NOT NULL,
  FOREIGN KEY (book_id) REFERENCES books(id) ON DELETE CASCADE
);

-- 书签表
CREATE TABLE bookmarks (
  id             INTEGER PRIMARY KEY AUTOINCREMENT,
  book_id        INTEGER NOT NULL,
  chapter_index  INTEGER NOT NULL,
  chapter_title  TEXT    NOT NULL DEFAULT '',
  excerpt        TEXT    NOT NULL DEFAULT '',
  offset_value   REAL    NOT NULL DEFAULT 0,
  created_at     INTEGER NOT NULL,
  FOREIGN KEY (book_id) REFERENCES books(id) ON DELETE CASCADE
);
CREATE INDEX idx_bookmarks_book ON bookmarks(book_id);

-- 书源表：rule_yaml 存原始 YAML 文本，解析失败可恢复
CREATE TABLE book_sources (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  name       TEXT    NOT NULL,
  url        TEXT    NOT NULL,
  src_group  TEXT    NOT NULL DEFAULT '',
  enabled    INTEGER NOT NULL DEFAULT 1,   -- 0/1
  sort       INTEGER NOT NULL DEFAULT 0,
  rule_yaml  TEXT    NOT NULL,
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);

-- 笔记表：mark=划线 / annot=批注 / excerpt=书摘（对齐蜗牛读书交互）
CREATE TABLE notes (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  book_id       INTEGER NOT NULL,
  chapter_index INTEGER NOT NULL,
  type          TEXT    NOT NULL,           -- mark | annot | excerpt
  color         TEXT    NOT NULL DEFAULT 'yellow',
  text          TEXT    NOT NULL,           -- 原文（划线/批注对象）
  thought       TEXT    NOT NULL DEFAULT '',-- 想法（仅批注）
  created_at    INTEGER NOT NULL,
  FOREIGN KEY (book_id) REFERENCES books(id) ON DELETE CASCADE
);
CREATE INDEX idx_notes_book ON notes(book_id);
```

## 3. 设计说明

### 3.1 关键决策

| 决策 | 理由 |
|---|---|
| `books.origin` 区分 local/network | 书架混合两种来源；本地书走文件缓存，网络书走书源引擎 |
| 章节正文不入库 | TXT 解析结果与 EPUB 抽取文本写入 `<appDir>/books/<id>/chapters.json`；数据库只存元数据。理由：正文可达数 MB，入库会拖垮查询 |
| `toc_json` 缓存网络书目录 | 避免每次打开都请求一次目录页；`updated_at` 可由后续刷新策略管理 |
| `reading_progress` 一书一行（主键 book_id） | 进度是「当前值」不是流水；历史统计二期用独立 `reading_stats` 表 |
| 外键 `ON DELETE CASCADE` | 删书时进度/书签/笔记自动清理（原项目需手工删多个 SharedPreferences 键） |
| `enabled` 用 INTEGER 0/1 | SQLite 无布尔类型 |
| 时间戳统一 `millisecondsSinceEpoch` | 与 SharedPreferences 旧数据兼容，便于未来导入 |

### 3.2 索引策略

- `idx_books_category`：书架按分类筛选（最热查询）
- `idx_books_origin`：「仅看本地/仅看网络」过滤
- `idx_bookmarks_book` / `idx_notes_book`：打开书籍时加载其书签/笔记

### 3.3 迁移策略（v1 → v2+）

```dart
onUpgrade: (db, oldVersion, newVersion) async {
  if (oldVersion < 2) {
    // 示例：v2 新增 reading_stats 表
    // await db.execute('CREATE TABLE reading_stats (...)');
  }
},
```
规则：**只增不改**——不删列不改名，新列给默认值；备份格式带 `version` 字段，恢复时按版本兼容。

### 3.4 章节文件缓存布局

```
<appDocuments>/books/<bookId>/
  ├── chapters.json     # [{"title":"第一章 ...","url":"","body":"..."}, ...]
  └── cover.jpg         # EPUB 解出的封面（可选）
```
- 本地书：导入时一次性解析写入；
- 网络书：目录写入 `chapters.json`（body 为空），阅读某章时抓取正文并回填；
- 删除书籍 = 删数据库行 + 删目录（Repository 内事务化处理）。
